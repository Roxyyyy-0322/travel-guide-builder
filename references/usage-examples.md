# 调用示例与迁移

这些是输入示例，不是已调研行程；不得把示例日期、价格或目的地偷偷作为默认值。

## 网页

```text
使用 $travel-guide-builder
目的地：成都，周边可安排一天
时间：2027-04-10至2027-04-14
偏好：两位成年人，美食、博物馆，少爬坡，每天10点出门、21点结束
预算：两人共8000元，含住宿，不含往返机票
输出：可转发网页，分分页，需要路线地图
隐私：普适版，不放个人支付和订单
机票酒店：尚未购买
```

## PDF

```text
使用 $travel-guide-builder
目的地：巴黎和里昂
时间：2027-09-05至2027-09-13
偏好：第一次出国，艺术、美食，公共交通，少换酒店
输出：A4完整详细PDF，含逐段交通、预约步骤和新手指南
预算：先估算，以每人欧元计价，人民币换算另列
隐私：保留日期与建议住宿区域，不放联系方式、个人支付和预订记录
出发地与国籍：如需判断入境要求，请再问我
```

## 更新已有攻略

```text
使用 $travel-guide-builder，把现有攻略的第3天改为室内活动。
保留已经确定的预约；同步更新路线、预算、票券和购物安排。
仍输出原来的网页，并重新生成同版PDF；不要保留废弃方案。
```

## 在另一台设备使用

把压缩包中的travel-guide-builder文件夹放进目标Codex的skills目录（通常为~/.codex/skills），不要多套一层文件夹；在新会话中用$travel-guide-builder调用。若技能未被发现，重新加载应用后检查目录和SKILL.md。技能需要具备联网研究、文件生成能力的助手运行，不是独立双击应用；网页公开发布还需可用托管能力，PDF需可用排版库及对应文字字体。
