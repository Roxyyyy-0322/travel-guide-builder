# 旅行攻略生成器

输入目的地、旅行日期和偏好，生成详细旅行网页或独立排版PDF。

包含逐段交通、门票预约、票券比较、购物退税、
新手指南、预算和路线地图。

## 安装

下载本仓库，将文件放入：
~/.codex/skills/travel-guide-builder/

确保该文件夹内直接包含 SKILL.md。

## 使用

在 Codex 新会话中输入：

使用 $travel-guide-builder
目的地：……
日期：……（含年份）
偏好：……
人数和预算：……
输出：网页 / PDF / 两者

## 运行条件

需要具备联网研究和文件生成能力的助手。
网页公开分享需要另外发布到托管平台。
